# ⚔️ Angličtina RPG

Zábavná akční RPG hra na učení angličtiny. Každé cvičení je souboj s bossem – za správně přeložená
slovíčka získáváš energii ⚡, kterou utrácíš za útoky (Seknutí, Ohnivá koule, Ultimátní úder) a léčení.

## Jak hrát
1. Zadej jméno hrdiny a vyber svou pokročilost (A1–C1).
2. Na mapě vyber bosse (další se odemykají postupně).
3. V souboji přeložte české slovo do angličtiny (u B2/C1 se odpověď píše).
4. Správné odpovědi dávají energii a kombo, chyby způsobí útok bosse.
5. Energii použij na útoky a porazit bosse. Za výhru dostaneš XP a postoupíš o level.

## Spuštění
Otevři `index.html` v prohlížeči – žádná instalace ani build není potřeba.
Hru lze také zprovoznit přes GitHub Pages (Settings → Pages → větev `main`).
